
## Небольшое превью:

Данный проект представляет собой результат системного анализа и проектирования автоматизированной информационной системы (АИС) для самообслуживания покупателей в розничном магазине. 
В рамках работы была спроектирована архитектура системы, построены UML-диаграммы, выделены ключевые сущности, их атрибуты и взаимосвязи. Проект демонстрирует навыки системного анализа, объектно-ориентированного проектирования и моделирования бизнес-процессов.


##  Цель проектов:

Спроектировать архитектуру системы самообслуживания, которая позволяет покупателям самостоятельно:
- регистрировать товары с помощью сканера штрих-кодов;
- взвешивать товары на встроенных весах;
- искать товары по названию или категории;
- применять скидочные карты;
- оплачивать покупки банковской картой или через PayPal;
- получать чек после успешной оплаты.

Система также обеспечивает:
- управление товарами и скидками (товаровед);
- помощь покупателям и контроль касс (администратор);
- генерацию аналитических отчётов (руководитель, товаровед);
- учёт просроченных товаров.
